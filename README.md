# 🎮 Tic Tac Toe

A modern, responsive, and minimalist implementation of the classic Tic Tac Toe game. Built with pure vanilla JavaScript — no frameworks, no dependencies. Features a retro-neon glow aesthetic, smooth animations, and a persistent score tracker.

## ✨ Features

* **Sleek Animated UI:** Title slides in on load with a smooth entrance animation that sets the tone.
* **Retro-Neon Aesthetics:** Player pieces feature a vibrant neon glow effect against a moody gradient background.
* **Robust Game Logic:** Automatic win detection across all rows, columns, and diagonals with instant feedback.
* **Score Tracker:** Persistent scoreboard that survives across rounds — reset only when you choose to.
* **Draw Detection:** Recognizes a Cat's Game when the board fills with no winner.
* **One-Click Restart:** Clear the board and jump into the next round without losing your scores.
* **Fully Responsive:** Scales cleanly across desktop and mobile screens.

## 🛠️ Tech Stack

* **HTML5** — Semantic structure
* **CSS3** — Grid layout, keyframe animations, glow effects, and media queries
* **JavaScript (ES6+)** — Game logic, state management, and score tracking

## 🚀 How to Play

1. Player **X** always starts the game.
2. Players take turns clicking on any empty cell in the 3×3 grid.
3. The first player to align three symbols horizontally, vertically, or diagonally wins!
4. Click **Restart** to start a new round — scores carry over.
5. Click **Reset Score** to wipe the scoreboard and start fresh.
